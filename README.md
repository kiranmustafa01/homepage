# auraT — Style, with intention

A responsive React + Vite project showcase homepage for auraT, an AI personal styling concept.

## Features

- Semantic HTML landmarks: header, navigation, main, sections and footer
- Responsive desktop and mobile layouts
- Accessible navigation labels and descriptive image alt text
- Reduced-motion support
- Three project showcase cards and a contact call to action

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel from GitHub

1. Push this project to a GitHub repository on the `main` branch.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the framework preset as **Vite**. Use `npm run build` as the build command and `dist` as the output directory.
4. Deploy. In Vercel project settings, confirm the production branch is `main`.
5. Every subsequent push to `main` will trigger a production deployment.
